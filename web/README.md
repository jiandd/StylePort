# 过片 · StylePort Web

StylePort 的浏览器版本。它复用原生 App 的 HEIC 容器补写规则，把支持「摄影风格 2」的 iPhone HEIC 照片转换为包含「摄影风格 3」数据的副本。

## 打开方式

直接用 Safari、Chrome 或 Edge 打开 `index.html`。页面不依赖服务器、账号或网络请求，照片只会在当前浏览器标签页内读取和处理。

如果需要通过网址访问，把整个 `web` 目录作为静态网站发布即可。不需要安装依赖或执行构建命令。

## 功能

- 多选或拖放 HEIC / HEIF 照片
- 本地批量转换，不重新编码主图
- 自动跳过已包含摄影风格 3 或不兼容的照片
- 输出文件名追加 `_GP`
- 单张下载和批量下载
- 桌面与手机响应式界面

网页版处理所选 HEIC 照片本体，不重建实况照片的视频配对、iCloud 相册编辑记录或完整 PhotoKit 保存链路。需要完整实装到系统照片 App 的实况照片流程时，请使用原生 StylePort App。

## 验证

转换内核已与原生 Swift 实现使用真实 HEIC 样本逐字节对照。网页端到端测试会验证：

- 选择文件后正确识别为可转换
- 转换按钮、进度和结果状态正常
- 生成的下载链接有效
- 输出文件大小及 SHA-256 与原生版本完全一致

## 许可
